# target-txt 文本正则化

用于 `meta.text_normed`。实现：`normalize_target_txt()`。

目标是保留可读的识别文本，不做口语化 Text Normalization。

## 流程

```text
原始 text
-> 清洗标记
-> 删除结构标签
-> Unicode NFC + 全角字母数字转半角
-> 弯撇号转 ASCII
-> 百分号前置空格压缩
-> 保护标识符、数字、URL 等片段
-> 空白压缩
-> 英文/拉丁字母小写
-> 中英文边界空格处理
-> 标点空格清理
-> 恢复保护片段
-> text_normed
```

## 清洗标记

先处理源文本中的标记和转义：

- `html.unescape`：`&amp;` -> `&`，`&lt;` -> `<`
- 删除不可见/控制字符
- 删除 `#`、`*`、标注用 `&`、`&%&`
- 保留合法 `R&B`、`AT&T`、`Earth, Wind & Fire`
- `$` / `¥` 仅紧邻数字时保留
- `%` 仅在紧跟数字时保留

## 结构标签

成对的 `<...>`、`[...]`、`(...)`、`（...）` 一律删除，包括括号和内容，不区分已知/未知标签。

```text
a<b>c             -> ac
a[bc]d            -> ad
a(bc)d            -> ad
a（bc）d          -> ad
<sil> <pause>     -> ''
<unclear>         -> ''
<When You're Down And Out> -> ''
```

支持嵌套；未匹配的开括号只删除括号本身，未匹配的闭括号按普通标点处理。

## Unicode 处理

target-txt 使用 **NFC**，不是 NFKC：

- NFC 只做规范组合，合并等价字符序列
- 全角字母数字额外手动转半角：`ＡＢＣ１２３` -> `ABC123`
- 全角空格转普通空格
- 不做 NFKC 的兼容字符折叠，避免改变 `ﬁ`、`²` 等原始表面形式

结构标签在 Unicode 处理前已经删除。

## 受保护片段

以下内容保留原始表面形式，不送 TN、不翻译：

- URL、email、路径、hashtag、mention
- 日期、时间、版本号、单位
- 金额、百分比、数字、电话号码
- 标识符、缩写、产品名、专名
- `R&B`、`AT&T` 这类合法 `&` token

受保护片段只参与最后的空格和标点整理。

## 大小写与空格

- 普通英文/拉丁字母转小写
- 受保护片段保留原始大小写
- 中文与英文/数字边界补空格
- 中文标点恢复，英文标点后补空格
- 连续空白压缩为单空格

## 输出

保留标点和数字表面的可读文本，不做口语化 TN。示例：

```text
非常到位&嗯&          -> 非常到位嗯
我跟#迪姆#俩人         -> 我跟迪姆俩人
D&amp;D Beyond        -> D&D beyond
AT&amp;T's           -> AT&T's
（你好）               -> ''
```
